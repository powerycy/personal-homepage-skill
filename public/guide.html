PUBLIC USER GUIDE · 公开使用手册

三步做完，
拿走一个真网页。

这个工具不替你编经历。它负责把真实资料变成有结构、有风格、能直接发布的个人主页，并把最后的 HTML 文件交到你手里。

01

开始之前

准备好姓名、身份、一句话定位、3—5 句个人简介，以及至少一个能证明能力的项目。项目最好能讲清它解决什么问题、你负责什么、做了哪些功能、用了什么方法，以及目前的真实状态。

没有数字，也没关系。真实的“已开源”“正在内测”“完成可运行原型”，都比一个无法核对的漂亮数字更有说服力。
02

写入真实资料

  1. 打开 Studio，停留在“写入真实资料”。
  2. 把示例姓名、身份、简介和邮箱替换为自己的信息。
  3. 在“项目证据”里补齐问题、角色、功能、技术/方法和结果。
  4. 右侧预览会实时更新，资料自动保存在当前浏览器。

项目功能可以用中文顿号或逗号分隔，页面会自动把它们整理成可扫描的条目。

03

选择表达方式

进入第二步，在四种风格间切换。同一份资料不会丢失：

  • Signal：开发者、AI 创作者、开源作者。
  • Editorial：设计师、写作者、内容创作者。
  • Sunlit：独立开发者、自由职业者、年轻创作者。
  • Paper：求职者、顾问、产品与研究岗位。

桌面/手机按钮可以立即检查不同宽度，不需要刷新。

04

直接在预览里改

第三步点击“开启在线编辑”，预览中带虚线的文字都能直接修改。失去焦点后，修改会回写到资料对象。

导出的网页也能继续编辑。把鼠标移到导出网页左上角，会出现“编辑”和“导出 HTML”。按 E 可切换编辑，按 Ctrl / Cmd + S 保存。
05

导出与发布

  1. 点击“导出独立 HTML”。
  2. 浏览器会下载以姓名命名的 `.html` 文件。
  3. 双击即可离线打开；也可以上传到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态网站空间。
  4. 需要改文案时，可在导出网页里继续编辑并再次导出。
✓ 单文件，无构建步骤✓ 移动端响应式✓ 编辑内容写进新文件✓ 减少动效与键盘焦点
06

隐私与限制

Studio 不要求登录，填写的数据只保存在当前浏览器的 localStorage，生成和导出都在本地完成。清理浏览器数据会删除草稿，请及时导出。

它不会调用在线 AI 模型替你扩写经历，也不会自动生成用户评价、工作经历或成就数字。头像和多项目管理暂未进入这个比赛版本；需要更多内容时，可以先导出，再在 HTML 中继续编辑。
