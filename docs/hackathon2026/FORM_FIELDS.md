## 作品字段

**作品名称**

AI Personal Homepage Studio——把真实经历变成可发布的个人品牌网站

**作品类型 / 分类**

Web / H5；AI Coding 创作工具；个人品牌与作品集工具

**一句话描述**

输入真实个人资料，选择风格，在线编辑并导出一个可直接发布、可继续编辑的独立 HTML 个人主页。

**短描述（约 100 字）**

个人主页首先要讲清真实信息，再谈视觉。这个 Studio 把资料输入、四风格切换、桌面/手机预览、在线编辑和 HTML 导出做成一个无需登录的浏览器闭环，不自动编造指标、评价或经历。

**完整描述**

很多 AI 个人主页的问题不是模板少，而是内容空泛、项目证据弱、中文排版被忽略，以及用户最后拿不到能继续修改和发布的文件。AI Personal Homepage Studio 让用户填写姓名、身份、定位、简介和一个代表项目的真实证据链，再在四种视觉方向间无损切换，同时检查桌面和手机预览。用户可以直接点击预览文字修改，最后下载独立 HTML。导出文件自带隐藏编辑入口、稳定字段 ID、浏览器保存和再次导出能力。资料与生成都留在当前浏览器，产品运行时不调用在线模型，也不会自动补写数字、评价或工作经历。

**核心功能**

- 结构化真实资料输入；
- 4 种发布级风格无损切换；
- 桌面和手机实时预览；
- 基于稳定 `data-edit-id` 的在线编辑；
- 独立 HTML 导出、离线打开、二次编辑与再次导出；
- 浏览器本地保存、中文字体、减少动效和键盘焦点支持。

**创新点**
