# 使用手册

公开版：<https://powerycy.github.io/personal-homepage-skill/guide.html>

## 评委最快体验路径（约 1 分钟）

1. 打开公网产品链接，无需登录。
2. 在“写入真实资料”里修改“姓名 / 昵称”和“一句话定位”，观察右侧实时变化。
3. 点击“02 选择表达方式”，任选一个风格，确认同一份资料无损切换。
4. 点击右上角手机图标，检查手机预览。
5. 点击“03 编辑并导出”，开启在线编辑，直接改预览里的标题。
6. 点击“导出独立 HTML”，下载文件。
7. 打开下载文件，把鼠标移到左上角，点击“编辑”；修改后再次点击“导出 HTML”。

## 完整说明

- 项目功能可用顿号、中文逗号或英文逗号分隔，预览会自动拆成条目。
- 草稿自动写入当前浏览器的 localStorage。清理浏览器数据会删除草稿。
- 产品不上传资料，不要求账号，不提供云端同步。
- 项目链接只接受 `http` 或 `https` 协议；无链接时导出页不显示入口。
- 导出页按 `E` 切换编辑；按 `Ctrl/Cmd + S` 保存浏览器草稿。
- 导出的 HTML 可以离线打开，也可以上传到 GitHub Pages、Cloudflare Pages、Netlify 或其他静态托管。

## 测试账号与权限

不需要测试账号、密码、API Key、地理位置、摄像头或麦克风权限。

## 已知边界

比赛版本聚焦“一份个人资料 + 一个代表项目”的最短发布闭环。头像上传、多项目管理和云端协作不在本版范围内。需要更多项目时，可以先导出，再在 HTML 中继续扩展。
