# 项目介绍

## 一句话

输入真实个人资料，选一种适合自己的表达方式，边看边改，最后下载一个能直接发布的个人主页 HTML。

## 为什么做

现在用 AI 做页面不难，难的是不把每个人都做成同一种页面。个人主页最常见的问题不是“少一个模板”，而是三件更具体的事：不知道该写什么；AI 为了让页面看起来完整而编数字、编评价；效果图很漂亮，但用户拿不到一个能继续修改和发布的文件。

这个项目的判断是：个人主页首先是内容结构工具，其次才是视觉工具。它必须先回答“你是谁、做什么、有什么证据、下一步希望别人做什么”，再讨论动画和风格。

## 怎么解决

AI Personal Homepage Studio 把完整任务压缩成三步：

1. 填写姓名、身份、定位、简介和一个真实项目的证据链；
2. 在 Signal、Editorial、Sunlit、Paper 四种方向间无损切换；
3. 检查桌面/手机预览，直接点文字编辑，然后导出独立 HTML。

导出的文件不是一次性截图。它自带隐藏编辑入口、稳定字段 ID、浏览器保存和再次导出能力。用户离开 Studio 后仍然拥有自己的页面，不被平台绑定。

## 创意

- **反向约束生成。** 产品明确不自动补齐数字、评价和经历，把“缺信息”当作正常状态，而不是让模型美化成假事实。
- **风格与数据解耦。** 同一份资料可以切换视觉语言，不需要重复填写，也不会因为换模板丢内容。
- **把导出当产品能力。** 编辑后的 DOM 会被序列化进新文件；每次导出生成独立版本命名空间，避免旧 localStorage 覆盖新内容。
- **Skill 与可用产品合一。** 仓库既给 AI Agent 一套可执行的个人主页生成规则，也给评委一个无需安装的可操作 Studio。

## 实用性

适合求职者、独立开发者、设计师、内容创作者和自由职业者。没有账号、没有后端、没有复杂部署。用户可以在浏览器里完成内容整理和页面生成，再把 HTML 上传到任意静态托管空间。

## 完成度

- 公网产品与公开手册可直接访问；
- 资料输入、四风格切换、桌面/手机预览、在线编辑、HTML 导出全部可操作；
- 导出文件离线可打开、可编辑、可二次导出；
- 中文字体、键盘焦点、减少动效和移动端布局已覆盖；
- 桌面、手机、风格选择与成品预览快照齐全；
- 自动测试覆盖构建、规则、回归、导出往返和截图工具。

## 技术难点

1. React 预览中的编辑内容要回写集中式资料对象，切风格后仍能保留；
2. 导出页不能依赖原网页的 localStorage，需要把当前编辑后的 DOM 直接写进 HTML；
3. 每个可编辑字段使用语义化 `data-edit-id`，不能依赖 DOM 顺序；
4. 再次导出时生成新的 `data-edit-version`，隔离不同文件的浏览器草稿；
5. 预览在桌面工作区和 390px 手机容器中使用同一套组件完成响应式降级；
6. 全流程在浏览器本地完成，同时保证链接、HTML 转义和协议白名单。

## AI 参与说明

本项目使用 AI Coding 助手参与仓库审计、需求拆解、前端实现、测试脚本、视觉检查和报名文案整理。作者负责比赛目标、产品取舍、事实边界、账号与最终提交责任。公网 Studio 本身是确定性的浏览器应用，运行时不调用在线 AI 模型，也不会根据输入自动编造个人经历。
