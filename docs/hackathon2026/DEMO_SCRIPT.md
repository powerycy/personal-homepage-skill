# 90 秒演示脚本

## 0—12 秒：问题

“用 AI 做一个漂亮页面已经很容易，但个人主页还是经常长得一样，还会为了看起来完整而编数字、编评价。我的判断是：个人主页首先是内容结构工具，视觉排在后面。”

画面：打开 Studio 主界面。

## 12—32 秒：真实资料输入

“这里先填姓名、定位、简介和一个代表项目。项目不要求漂亮数字，但必须说清解决的问题、自己的角色、功能、方法和真实状态。”

操作：修改姓名和一句话定位，展示右侧实时变化。

## 32—47 秒：风格切换

“同一份资料可以直接切换四种表达方式，内容不丢。开发者可以用 Signal，设计和内容创作者可以用 Editorial，求职者可以用 Paper。”

操作：切换 Editorial，再切手机预览。

## 47—67 秒：在线编辑

“如果看到预览后还想改，直接点文字就能编辑。每个字段都有稳定 ID，换样式后不会串内容。”

操作：进入第三步，开启在线编辑，改一句标题。

## 67—85 秒：导出闭环

“最后下载的是一个独立 HTML，不是截图。离开 Studio 后，左上角仍能继续编辑，再导出一个把修改写进文件的新版本。”

操作：导出，打开下载文件，二次编辑并再次导出。

## 85—90 秒：收束

“它不替你编人生，只把真实经历变成一个你真正拥有、能直接发布的网站。”
