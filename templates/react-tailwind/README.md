# React + Tailwind Personal Homepage Starter

Use these files as a stable skeleton for Vite React personal homepage projects.

- `profile.ts` centralizes content.
- `App.tsx` renders semantic homepage sections.
- `index.css` defines CJK-safe font tokens and motion/accessibility basics.

Replace `待补充` with user-provided facts only. Do not invent results, links, awards, or metrics.
